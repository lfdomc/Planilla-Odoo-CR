📷 Reconocimiento Facial — Asistencias

Odoo 19 hr.attendance face_recognition OWL 3

Módulo completo de reconocimiento facial integrado con hr.attendance de Odoo 19. Permite a los empleados registrar entradas y salidas usando la cámara web, sin tarjetas ni PINs.

✨ Características

🎯 Reconocimiento Automático

Detecta y reconoce rostros automáticamente cada 2.5 segundos. No requiere interacción manual.

🔗 Integración hr.attendance

Crea y cierra registros de asistencia directamente en el módulo nativo de Odoo.

🖥️ Quiosco de Asistencia

Pantalla dedicada en tiempo real con reloj, resultado y estado visual para colocar en la entrada.

⚡ Entrada/Salida Automática

Detecta automáticamente si el empleado está entrando o saliendo según su estado actual.

📊 Historial Completo

Registro detallado de cada reconocimiento: confianza, imagen capturada, IP del dispositivo.

⚙️ Configuración Flexible

Tolerancia, umbral de confianza y modelo de detección configurables desde Ajustes.

📋 Requisitos

Python (servidor Odoo)

pip install face_recognition numpy Pillow
⚠️ Nota: face_recognition requiere dlib y compiladores C++. En Ubuntu/Debian: sudo apt install cmake build-essential libopenblas-dev liblapack-dev

Modelos de detección

  • HOG (recomendado): Rápido, funciona en CPU. Ideal para producción.
  • CNN: Más preciso, requiere GPU/CUDA. Para entornos con GPU disponible.

🚀 Instalación

1. Copie la carpeta facial_attendance/ al directorio de addons de Odoo.
2. Instale las dependencias Python en el entorno del servidor.
3. Reinicie el servidor Odoo.
4. Active el modo desarrollador en Odoo (Ajustes → Modo Desarrollador).
5. Vaya a Aplicaciones → Actualizar lista de aplicaciones.
6. Busque "Reconocimiento Facial" e instale el módulo.

🔧 Uso

Registrar rostro de un empleado

  1. Vaya a Empleados → [Empleado] → Pestaña "Reconocimiento Facial"
  2. Haga clic en "Registrar Rostro"
  3. Permita el acceso a la cámara en el navegador
  4. Capture la foto y haga clic en "Guardar Registro"

Quiosco de asistencia

  1. Vaya a Asistencias → Reconocimiento Facial → Abrir Quiosco
  2. La pantalla mostrará la cámara en tiempo real
  3. Los empleados solo deben mirar a la cámara para registrar su asistencia
💡 Consejo: Para uso como quiosco permanente, abra la URL /facial_attendance/kiosk/public en modo pantalla completa (F11). Esta URL no requiere login de Odoo.
